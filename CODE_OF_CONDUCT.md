# Code of Conduct

## The short version

Be decent. Assume the other person is acting in good faith and knows something
you do not.

## Expected behaviour

- Give people the benefit of the doubt, especially across a language barrier.
- Critique code and claims, not people.
- Accept that "this failed for me in production" is evidence, and so is "that
  is no longer true" — both are how the platform docs here stay accurate.

## Unacceptable behaviour

Harassment, personal attacks, demeaning comments, publishing others' private
information, and sustained disruption of discussion.

## Reporting

Report unacceptable behaviour by opening a private security advisory on this
repository, or by contacting the maintainer directly. Reports will be handled
confidentially. The maintainer may remove comments, close issues, or block
accounts that violate this document.

## Scope

This applies in the repository's issues, pull requests and discussions, and in
any space where someone is representing the project.
